# Конспекты лекций SSAU

Репозиторий заполняется **автоматически** ботом. Руками тут ничего не редактируется — при следующей паре файлы перезапишутся.

## Что внутри

```
<Предмет>/
  лекция-1/
    transcript.txt   # расшифровка речи с пары
    notes.pdf        # конспект
  лекция-2/
    ...
```

- `transcript.txt` — расшифровка аудио лекции (STT).
- `notes.pdf` — конспект, собранный LLM.

## Структура конспекта

PDF начинается с раздела **«Организационное»**: что и к какому сроку сдавать, дедлайны, требования по лабам/курсовым/контрольным, тесты, Moodle, форма отчётности — всё, что преподаватель говорил про организацию. Если про это не говорили, так и написано.

Дальше — тема, план, основные определения, разбор материала по ходу лекции, формулы и примеры, выводы, вопросы к зачёту.

## Как это работает

1. Бот заходит на онлайн-пару гостем (без микрофона и камеры, только слушает).
2. Пишет звук, после пары распознаёт речь в текст.
3. LLM собирает конспект из расшифровки.
4. Файлы выгружаются сюда; локально на сервере аудио удаляется сразу, `transcript.txt` и `notes.pdf` хранятся ~сутки.

Порядок `лекция-N` — хронологический в рамках предмета.

> Материалы носят учебный характер и собраны автоматически; возможны ошибки распознавания.
